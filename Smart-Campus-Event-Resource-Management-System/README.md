# Smart Campus Event & Resource Management System

A GitHub-ready **Web Technology Lab project** for managing campus events and resources.

## Project Overview

SmartCampus is a web application that allows students to:

- View upcoming campus events
- Search and filter events
- Register for events
- View their registrations
- View campus resources
- Request resource bookings
- Manage their student profile
- Contact campus support

Administrators can:

- Login to an admin dashboard
- Add and delete events
- Add and delete campus resources
- View student event registrations
- View and approve resource booking requests
- View registered students

## Technologies
